# Purpose

The Theme Vocabulary provides a shared language for describing the enduring ideas explored by books in the MFEE Living Library.

Unlike subjects, which describe what a book is about, themes describe the ideas, values, emotions, and experiences that readers may encounter through a story.

Themes support discovery, recommendations, instructional planning, and meaningful conversations about books.

The purpose of this vocabulary is not to describe books perfectly.

Its purpose is to help people discover them.

---

# Guiding Principles

Every theme should be:

- Meaningful to readers
- Easy to understand
- Broad enough to apply across many books
- Distinct from other themes
- Useful for discovery

Whenever possible, themes should describe enduring ideas rather than plot details.

# Vocabulary Governance

The Theme Vocabulary is a living resource.

New themes may be proposed by educators, tutors, students, families, librarians, or future AI-assisted cataloging tools.

All proposed themes should be reviewed before being added to the approved vocabulary.

The goal is thoughtful growth rather than rapid expansion.

---

# Proposal Process

Every proposed theme should answer three questions.

1. Does this theme improve discovery?

2. Is it understandable to educators, families, and students?

3. Is it meaningfully different from existing themes?

Only themes that satisfy all three questions should be added.

---

# Relationship to the Living Library

The Theme Vocabulary is one component of the Living Library Discovery Taxonomy.

Together with Subjects, Representation, Instructional Supports, and Community Knowledge, it helps transform a traditional library catalog into a richer discovery experience.
