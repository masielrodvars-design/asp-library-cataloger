# Small Library Cataloger

*A smarter way to build and maintain library catalogs for schools, nonprofits, classrooms, and community libraries.*

---

## Overview

Small Library Cataloger is a configurable library catalog management platform designed to help small organizations organize and maintain professional-quality book collections without the cost or complexity of traditional library software.

The platform combines authoritative metadata, configurable cataloging standards, artificial intelligence, and human review to dramatically reduce the time required to catalog and manage a library.

The software is being developed and owned by **Masiel Rodriquez-Vars**, with the **Montclair Fund for Educational Excellence (MFEE)** serving as the primary implementation and testing partner.

---

## Vision

Small organizations deserve modern library software.

Many schools, nonprofits, literacy organizations, afterschool programs, and classroom libraries manage thousands of books using spreadsheets because professional library systems are often too expensive, too complex, or designed for much larger institutions.

Small Library Cataloger bridges that gap by combining automation with human expertise.

Rather than replacing librarians or volunteers, the software acts as an intelligent cataloging assistant that makes recommendations, explains its reasoning, and learns from user decisions over time.

## Core Features

### Catalog Import

- Goodreads import
- Excel import
- CSV import
- Future Google Sheets integration

### Metadata Enrichment

Automatically retrieve:

- Language
- Publisher
- Publication information
- Subjects
- Book descriptions
- Audience information
- ISBN validation
- Cover images

### Catalog Intelligence

Automatically recommend:

- Collection codes
- Call numbers
- Themes
- Representation tags
- Format tags
- Reading levels (future)

### Human Review

Every recommendation includes:

- Confidence score
- Explanation
- Supporting metadata

Users always make the final decision.

### Collaboration

Planned support for:

- Airtable
- Google Sheets
- Multi-user review workflows
- Volunteer assignments

### Publishing

Export clean catalogs to:

- Excel
- Google Sheets
- CSV
- PDF reports
- Shelf labels (planned)

---

## Design Principles

- Human expertise comes first.
- AI makes recommendations—not final decisions.
- Recommendations should be explainable.
- Metadata should come from authoritative sources whenever possible.
- Cataloging standards should be configurable.
- Organizations own their data.
- The software should learn from user feedback.
